# List Manipulation

A menu-driven Python project for performing common operations on a Python list.

## Overview

This project provides an interactive menu to manage a list. The user can enter and display a list, search for values, add or update elements, delete elements, sort the list, find maximum/minimum values, and exit.

The original project document contains the implementation and example console outputs for the major operations.

## Features

| Option | Operation |
|---|---|
| 1 | Enter list |
| 2 | Display list |
| 3 | Search an element |
| 4 | Add elements |
| 5 | Update an element |
| 6 | Delete elements |
| 7 | Sort list |
| 8 | Display maximum/minimum |
| 9 | Exit |

### Add submenu
- Add one element at the end using `append()`
- Add multiple elements at the end using `extend()`
- Insert an element at a selected index using `insert()`

### Delete submenu
- Delete by index using `pop()`
- Delete by value using `remove()`
- Clear the complete list using `clear()`

### Sort submenu
- Ascending order using `sort()`
- Descending order using `sort(reverse=True)`

## How to Run

1. Install Python 3.
2. Save the project program as a `.py` file.
3. Open a terminal/command prompt in the project folder.
4. Run:

```bash
python list_manipulation.py
```

5. Select an option from the displayed menu.
