# Problem Statement — List Manipulation

## Project Title
**List Manipulation**

## Student
**Arham Pathan — 26BAI10339**

## Problem
Develop a menu-driven Python program that allows a user to manage and manipulate the elements of a list interactively.

The program should provide options to:

1. Enter a list.
2. Display the current list.
3. Search for an element and report its index.
4. Add an element at the end, add multiple elements at the end, or insert an element at a selected index.
5. Update an element at a selected index.
6. Delete an element by index, delete an element by value, or clear the complete list.
7. Sort the list in ascending or descending order.
8. Display the maximum and minimum values.
9. Exit the program.

## Expected Outcome
The program should repeatedly display the main menu, execute the selected list operation, show the resulting list or requested information, and continue until the user chooses **Exit**.

- Python lists
- `append()`
- `extend()`
- `insert()`
- `index()`
- `pop()`
- `remove()`
- `clear()`
- `sort()`
- `max()` and `min()`
- `while` loops
- `if/elif/else` decision making
- User input and menu-driven programming
